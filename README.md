# Serpent Seeker

A web application developed as a first-year university project to explore front-end web development and interactive user experiences.

The application includes several working features, including an interactive quiz and an interactive map built using the Mapbox API. The project also incorporates external libraries and demonstrates the use of JavaScript, HTML and CSS to create a visually engaging web application.

The project remains unfinished, but provides an example of my early experience designing and developing web-based applications and working with third-party APIs and libraries.

## Technologies

* HTML
* CSS
* JavaScript
* Mapbox API
* External JavaScript libraries

## Key Features

* Interactive map using Mapbox
* Interactive quiz
* Interactive web interface
* Integration with external libraries and APIs
